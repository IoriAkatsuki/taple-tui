# taple-tui 2.0.0

1982 涉谷深夜爵士喫茶暖调胶片美学重构、温馨动态空状态，以及渲染与桥接性能优化。

## 主要更新

### 视觉美学与空状态体验
- **1982 涉谷暖调胶片 UI**：重构三层立体功放顶栏（含机架固定螺栓与 `PLAY / VU / LRC` 状态灯槽）、实体双色脊条 `NOW PLAYING` J-Card 卡片、独立 `│` 隔断烟熏 Nixie / 峰值保持亚像素 VU 仪表舱与立体声控台底栏。
- **涉谷窗景舞台与五款日系磁带**：拓展早/午/傍晚/深夜四时段多层木格窗景、胡桃木窗台唱片叠影与霓虹城市天际线，更新 `SHIBUYA`、`CHROME`、`NIXIE`、`X-RAY`、`CITYPOP` 五款经典磁带及黑胶/档案夹配色（保持无商标 TPS-L2 蓝银机身几何比例）。
- **暖光书桌小助手动态空状态**：为搜索初始/无结果/错误、未登录或连接中的资料库、空队列以及空歌词面板接入 2× 亚像素 SDF 矢量渲染的暖灯呼吸光晕、热咖蒸汽、打盹小助手与绕飞萤火虫，支持悬停操作胶囊唤醒微交互，`motion.Off` 下静止并在极窄/极矮窗口自动降级为简洁纯文本提示。

### 同步歌词、交互与性能
- **音节级同步歌词与滚筒特效**：支持 Apple Music TTML `<span begin/end/dur>` 逐音节渐进点亮、平滑滚动补间、暖石未播层级与行内粒子进度波前。
- **真实回读卷带动画**：seek 操作经 250ms 串行回读确认变化后驱动带盘高倍速卷绕、`KeyRew` / `KeyFF` 侧键下沉与动态模糊。
- **全链路渲染与桥接优化**：使用平面值类型 `npBuffer` 帧缓冲与池化 SGR 序列化消除逐帧接口装箱；新增浏览器异步启动 `OpenAsync`、单调 `queueRev` 增量队列快照、相邻未发送 `volume` / `seek` 合并、常驻图形渲染工作池、解析投影包围盒裁剪与分级待机帧率（满帧待机降至 8fps，`Tea.Blur` 与 `Subtle`/`Off` 停止无效空转）。

## 保留能力与运行边界（v1.2+ 基线）

- 完整保留 `--import-cookies FILE` 本地私有 Cookie 安全导入、独立无头 Chromium 运行时、Linux/Windows Vulkan Compute 与原生 macOS Metal 后端（生成 `walkman.metal` 与最新 `walkman.comp.spv` 严格匹配）。
- 完整播放仍需有效 Apple Music 订阅、运行时 AAC 解码与 Widevine DRM 支持；无账号 smoke 与 GPU 一致性测试不替代真实订阅账号播放验证。
- Windows/macOS 安装包未代码签名或公证，所有包均附带 `SHA256SUMS` 校验文件，仅在全部原生平台构建与测试通过后发布。
