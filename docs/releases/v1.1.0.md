# taple-tui 1.1

Apple Music 终端播放器，现提供 Windows、Linux 和 macOS 原生版本。

## 更新

- 蓝银 Walkman 磁带卡座、磁带收纳架、黑胶唱片箱与 3D 歌单档案夹。
- 歌曲 / 专辑 / 歌手搜索、个人资料库、播放队列和自动续播。
- 同步歌词、播放进度与操作设置面板。
- Vulkan GPU 加速与 CPU 回退；macOS 通过 MoltenVK 使用 Metal。
- Windows PowerShell 原生构建与便携 EXE 分发。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | 独立 `.exe` 或 `.zip`，在 PowerShell / Windows Terminal 中运行 |
| Ubuntu / Debian x64 | `.deb`，使用 `sudo apt install ./taple-tui_*_amd64.deb` |
| Fedora / RHEL / openSUSE x64 | `.rpm`，使用 `sudo dnf install ./taple-tui-*.rpm` |
| Linux x64 | `linux_amd64.tar.gz` |
| macOS Apple Silicon | `darwin_arm64.tar.gz` |
| macOS Intel | `darwin_amd64.tar.gz` |

解压后运行 `taple-tui`（Windows 为 `taple-tui.exe`）。运行需要 Chrome 和 Apple Music 订阅。macOS 可用 `brew install molten-vk` 启用 GPU 加速。Linux 系统混音电平表使用 `parec`。

`SHA256SUMS` 提供所有安装包的校验值。
